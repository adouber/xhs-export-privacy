小红书笔记导出

把小红书笔记一键转成阅读版 HTML / PDF / EPUB，可选 OCR 识别图中文字、收录评论。全部处理在本机完成，不上传任何数据。

下载安装 · v0.1.0

Edge 商店安装（推荐） 下载 ZIP（17.7 MB）

Edge 用户走商店安装即可自动更新；ZIP 供 Chrome / 不便访问商店的用户使用。

Chrome 用户安装 ZIP（三步）

  1. 下载并解压上面的 ZIP，得到一个文件夹
  2. 打开 chrome://extensions，右上角打开「开发者模式」
  3. 点「加载已解压的扩展程序」，选中解压出的文件夹

说明：Chrome 不允许直接安装商店外的 .crx 文件，加载解压目录是官方支持的方式。开发者模式提示「请停用开发者模式运行的扩展程序」时点取消即可，不影响使用。

功能

  • 三种出口，一份内容：阅读版 HTML / 可打印 PDF / EPUB 3（微信读书、Apple Books、Kindle 可导入）
  • OCR 图文识别：长图文章自动合并为连续正文，识别结果可校对编辑（可选）
  • 评论收录：主楼 + 楼中楼，收录情况如实标注
  • 隐私承诺：解析、图片下载、OCR 全部在浏览器本地完成，不收集、不上传、不追踪
